# Student Records Search

A simple student records web app built using ** HTML, CSS, and JavaScript **.

### Features

* Display student records in cards.
* Search students by *name or marks* .
* Dynamic filtering using JavaScript `filter()` .
* Responsive and clean UI.

### Technologies

* HTML
* CSS
* JavaScript

### Concepts Used

* `Arrays` 
* `Objects` 
* `forEach()` 
* `filter()` 
* `Arrow Functions` 
* `DOM Manipulation`
